# Pilot Kurum Seçim Kriterleri

## Amaç
Paketin gerçek dünyada doğrulanması için 5-7 pilot kurum seçimi.

## Portföy Çeşitlilik Matrisi

| Pilot | Tier | Sektör | Yargı Alanı | Özel Durum |
|-------|------|--------|-------------|------------|
| P1 | Tier 1 | Mevduat bankası | TR (BDDK) | Tam kapsam, CTPP var |
| P2 | Tier 2 | Sigorta | TR (SEDDK) | Orta ölçek |
| P3 | Tier 2 | Ödeme kuruluşu | TR (TCMB) | Yoğun API |
| P4 | Tier 3 | Katılım bankası | TR (BDDK) | Küçük ekip |
| P5 | Tier 1 | AB şubesi | AB (EBA) | Çoklu yargı |
| P6 | Tier 3 | Kamu finansman | TR | Kamu mevzuatı |
| P7 | Tier 2 | Kripto varlık | TR/AB | Yeni düzenleme |

## Seçim Süreci

### Faz 1: Keşif (4 hafta)
- Uzun liste: 20-30 aday
- Ön değerlendirme formu
- Kısa liste: 10-12
- Yerinde görüşmeler

### Faz 2: Sözleşme (4 hafta)
- Pilot sözleşmesi
- Veri işleme sözleşmesi
- Başarı kriterleri imzası
- Kick-off

### Faz 3: Uygulama (12-16 hafta)
- Onboarding wizard
- Gölge mod (2 hafta)
- Yarı-otomatik (1 ay)
- Haftalık geri bildirim

### Faz 4: Değerlendirme (4 hafta)
- Başarı kriterleri ölçümü
- Ders çıkarılanlar
- v2.0 paket güncellemesi
- Vaka çalışması

## Başarı Kriterleri (Özet)

- Olay sınıflandırma doğruluğu ≥ %95
- SLA ihlali = 0
- İnsan override ≤ %5
- Denetim izi bütünlüğü = %100
- Uyum maliyeti azalma ≥ %20
- NPS ≥ 40
